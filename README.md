# 学校就读评论口令

本仓库用短口令驱动半自动收录，方式对齐 `NuwaSkill-Yao`，但内容是学校学生体验，不是姚勇蒸馏。

## 发送这些口令

| 口令 | 做什么 |
| --- | --- |
| **收录就读文章** | PDF → 原文 DOCX + 分维评注副本，刷新《就读文章目录》 |
| **修改口令** | 调出「收录就读文章」完整提示词，然后等待你改 |
| **收录奇异文章** | 奇闻/吐槽/脑洞，独立序号，刷新《奇异文章目录》 |
| **更新目录** | 半自动刷新对话 Menu |

总表：`files/口令总表/*超级指令.docx`

PDF 归档到 `files/ZHIHU/`。不要读取 `Wushi/`，除非另行授权。
