# 合集

作者主页、多篇回答的合订摘录放这里。单篇就读体验仍走口令 **「收录就读文章」**，不要占用那边的序号。

## 这次怎么放

把 FireShot 主页 PDF 和原文链接一起发过来，并说明放进合集。不要读取 `Wushi/`，除非另行授权。

## 每次执行

1. PDF 只在 `合集/` 留一份，不复制到 `files/ZHIHU/`，除非同时要按单篇收录。
2. 优先用 PDF。只转写截图里看得见的标题和摘要；标了「阅读全文」却没展开的，不补造后文。
3. 去掉网页导航、私信数、广告、评论区和赞同条。
4. 生成合订 DOCX：文件名「序号＋作者＋短评价」。结尾写主页链接。
5. 分别记录截图里出现的发布时间、编辑时间和 PDF 快照；只显示到年或月时不补造。
6. 更新 `合集目录.json` 并运行 `更新合集目录.py`。学校或专业只填主页/回答里能确定的信息。

## 手动更新

```bash
python3 更新合集目录.py
```
