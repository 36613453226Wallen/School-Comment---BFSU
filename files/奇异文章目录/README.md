# 奇异文章目录

## 触发口令

> **收录奇异文章**

对应女娲库 `NuwaSkill-Yao` 里的 **「收录姚勇奇闻」**：主目录收正经就读体验，本目录收奇闻、吐槽、脑洞或趣味校园材料。序号独立，互不占用。

## 每次执行

1. PDF 归档到 `files/ZHIHU/`，不读取 `Wushi/`。
2. 从 PDF 识别正文、标题结构、首次发布及后续编辑时间；不访问受限页面补造内容。
3. 根据正文拟定有趣味的短标题，生成接近原文结构的可编辑 DOCX。
4. 从独立序号 1 开始，命名为 `1标题.docx`、`2标题.docx`。
5. 原文链接放在 DOCX 结尾。
6. 更新 `奇异目录.json` 并运行 `更新奇异文章目录.py`。
7. PDF 缺失时状态写「待PDF」，保留序号和链接。

## 手动更新

```bash
python3 更新奇异文章目录.py
```
