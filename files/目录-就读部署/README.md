# 目录-就读部署

## 更新方式

采用“半自动生成＋手动触发”：

1. `目录数据.json` 是可维护的目录源数据。
2. `更新目录.py` 根据源数据生成紧凑的 DOCX。
3. 平时不在每轮问答后自动改文件，避免高频提交、重复条目和目录噪声。
4. 用户说“更新目录”时：
   - 汇总上次更新时间之后的新对话；
   - 合并同一任务中的重复追问；
   - 补充问题总结、答案概要、模型和时间；
   - 更新 `updated_at`；
   - 运行脚本刷新 DOCX。

## 手动维护

也可以直接编辑 `目录数据.json`，在 `records` 末尾增加：

```json
{
  "id": 4,
  "question": "问题总结",
  "answer": "大概完成了什么",
  "model": "Cursor Grok 4.6",
  "time": "约/未知"
}
```

然后在本文件夹运行：

```bash
python3 更新目录.py
```

## 文件

- `目录-就读评论之Menu.docx`：浏览用目录。
- `目录数据.json`：半自动生成的数据源，也可人工编辑。
- `更新目录.py`：DOCX 生成器。
