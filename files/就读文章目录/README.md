# 就读文章目录

## 触发口令

以后发送：

> **收录就读文章**

并同时提供或上传新文章 PDF、原文链接。

## 每次执行

1. 将 PDF 保存到 `files/ZHIHU/`；不得读取 `Wushi/`（`WuShi/`），除非另行授权。
2. 优先使用 PDF。识别正文、一级/二级标题、引用、编号列表和发布时间；去掉网页导航、私信数、广告及评论区。
3. 生成接近原文排版的**原文 DOCX**。文件名只保留「序号＋正文标题」，标题要带短问句和总评价，并且有趣味，不套死板句式。
4. 原文 DOCX 与标题保持不动。另存内容相同的**分维评注副本**（建议文件名：`序号标题.分维评注.docx`）：标出分论点/评价维度、支撑句和理由、是否中肯，并留讨论空白。两份 DOCX 结尾都写知乎原文链接。
5. 分别记录首次发布时间、后续编辑时间和 PDF 快照时间；截图只显示到年或月时不补造日期。
6. 更新 `文章目录.json` 并运行 `更新就读文章目录.py`。目录至少显示序号、DOCX 全名、时间、学校、专业、状态。学校或专业无法判断时，在对话里提问，不擅自改名。
7. PDF 尚未出现或无法读取时，不访问受限网页补造正文；保留序号和链接，状态写「待PDF」，并写明缺什么。

奇闻、吐槽、脑洞材料使用并列口令 **「收录奇异文章」**，归入 `../奇异文章目录/`，从独立序号 1 开始。

要改本口令的提示词，发送 **「修改口令」**。

## 手动更新

```bash
python3 更新就读文章目录.py
```
