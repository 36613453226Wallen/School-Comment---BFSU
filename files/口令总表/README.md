# 口令总表

发送下面的短词即可触发。新口令必须登记进 `超级指令.json`，不能只写在聊天里。

```bash
python3 登记指令.py \
  --keyword "新口令" \
  --type "关键词口令" \
  --purpose "一句话用途" \
  --inputs "需要用户提供什么" \
  --operation "逐步做什么" \
  --outputs "生成哪些文件"
```

## 当前口令

- **收录就读文章**：把学校就读体验 PDF 转成原文 DOCX + 分维评注副本，并刷新《就读文章目录》。
- **修改口令**：调出「收录就读文章」完整提示词，然后等待你的修改。
- **收录奇异文章**：奇闻/吐槽/脑洞类材料，独立序号，刷新《奇异文章目录》。
- **更新目录**：半自动刷新对话 Menu（平时不自动改文件）。

数据源：`超级指令.json`。排版文件：`*超级指令.docx`。
